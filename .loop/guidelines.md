- csx-warnings: 스키마(a, #831)와 수집(b, #832)은 병합됨. 화면(c)은 답 비율·속도·외부 사용자와 연결이 약해 1번 마일스톤 뒤로 미룬다. 원격 MCP 답에 이미 모은 경고를 함께 싣는 정도만 노드 3 에서 한다.
- csx-slowapi: 보류. 느린 API 는 1번 마일스톤 노드 2 에서 같이 본다.

재계획 규칙
- 노드가 끝날 때마다 `.loop/kpi-probe.py` 로 100개를 다시 재고 위 표의 현재값·측정 시각을 고친 뒤 다음 노드를 고른다. 원자료는 `docs/evidence/kpi-probe-<날짜>.jsonl` 에 남긴다.
- 숫자가 없으면 '데이터 없음'으로 두고 지어내지 않는다.
- 정리·리팩토링은 위 KPI 중 하나를 올리는 노드 안에서만 한다.
- 새 비용·출시·삭제·커뮤니티 게시·가입은 의종 확인을 받는다.
