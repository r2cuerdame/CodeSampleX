API 활동 ID

여기 있는 수는 API 활동 ID의 개수입니다. 사람 수가 아니고, 실제 사용자 수도, MCP 클라이언트나 세션 수도, 설치 수도 아닙니다. 한 사람이 여러 네트워크에서 접속하면 여러 ID로, 여러 사람이 공유 NAT·통신사망·회사망을 사용하면 하나의 ID로 셉니다. 네트워크 추정치이며 소유자 네트워크 제외 후의 값이고, 사람/사용자 수가 아님을 다시 밝힙니다. 소유자 제외는 같은 네트워크의 다른 활동도 해당 UTC 일·월 동안 함께 제외하는 되돌릴 수 없는 버킷 승격이므로, 관리 화면은 공유망이 아닌 안정적인 전용 네트워크에서 여는 것이 안전합니다. ‘오늘’과 ‘이번 달’은 진행 중인 부분 기간입니다. ‘이번 달’은 최근 30일이 아니라 달력 기준 월(UTC 1일부터 말일까지)이며, 매월 1일 0시 UTC에 새로 시작합니다. 이 활동 추정 수집기는 IP·전달 헤더·User-Agent·경로·질의 문자열을 활동 추정 저장소에 저장하지 않으며, 일 ID와 월 ID는 키 도메인이 달라 서로 연결되지 않습니다. 다만 이 값은 익명값이 아니라 키 기반 가명값입니다. 같은 서버의 CSX_ACTIVITY_HASH_KEY가 개인정보 보호 경계이며, 키와 DB가 함께 유출되면 IPv4 버킷은 2^32 주소 공간 열거로 원래 주소 후보를 복원할 수 있습니다. 보존 범위는 키가 없거나 잘못되어 수집이 꺼진 동안에도 현재 UTC 기간을 포함해 일 버킷 35개·월 버킷 13개로 정리됩니다. 서버의 다른 기능이 사용하는 저장소에 대한 설명은 아닙니다.
